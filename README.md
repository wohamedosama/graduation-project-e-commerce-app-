<h1>🛍️ E-Commerce Flutter App</h1>

<p>
  A scalable and modern E-Commerce mobile application built using Flutter & Dart
  as part of my graduation project. The app demonstrates a complete shopping
  experience with clean architecture, Bloc/Cubit state management, dynamic UI,
  and smooth user interactions.
</p>

<hr />

<h2>✨ Features</h2>
<ul>
  <li>🛒 Full product catalog with categories</li>
  <li>🔎 Product search & filter</li>
  <li>📦 Shopping cart with add/remove functionality</li>
  <li>🧑‍💻 User authentication (sign in / sign up)</li>
  <li>❤️ Wishlist management</li>
  <li>💳 Checkout simulation (no real payments)</li>
  <li>📍 Clean UI with responsive layouts</li>
  <li>⚡ Smooth performance & animations</li>
</ul>

<hr />

<h2>🛠 Tech Stack</h2>
<ul>
  <li><strong>Flutter</strong> — UI framework</li>
  <li><strong>Dart</strong> — Programming language</li>
  <li><strong>Bloc / Cubit</strong> — State management</li>
  <li><strong>REST API</strong> — Backend data integration (optional)</li>
  <li><strong>Git & GitHub</strong> — Version control</li>
</ul>

<h2>📦 Installation</h2>

<pre>
